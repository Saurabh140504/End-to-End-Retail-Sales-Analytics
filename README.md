# Retail Sales Analytics Project

## End-to-End Data Analyst Project

## Project Overview

This project focuses on analyzing retail sales data to identify business insights related to sales performance, customer behavior, product performance, and revenue trends.

The project was built using:

* Excel for handling messy dataset
* Python for data cleaning and analysis
* MySQL for business query analysis
* Power BI for interactive dashboard creation

---

# Business Problem

The retail company faced multiple business challenges:

* Fluctuating monthly sales performance
* Low-performing product categories
* No centralized dashboard system
* Difficulty identifying top customers
* Manual reporting process
* Slow business decision-making
* Lack of customer behavior insights

The goal of this project is to transform raw retail sales data into meaningful business insights and interactive dashboards.
